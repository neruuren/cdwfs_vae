# Référentiel VAE : Concepteur Développeur Web Full Stack (RNCP 39608)

Ce skill est la **référence** des autres skills VAE du projet. Il ne modifie rien : il sert à savoir ce qui est attendu.

| Élément | Valeur |
|---|---|
| Intitulé | Concepteur Développeur Web Full Stack |
| Code | RNCP 39608 |
| Niveau | 6 (Bac+3, équivalent licence/bachelor) |
| Certificateur | Association pour la gestion de 3iL (3iL Ingénieurs, Limoges) |
| Enregistrement | 2024-10-01, échéance 2029-10-01 |

## Les 4 blocs

| Bloc | Intitulé court | Compétences | Ce que la formation initiale fait évaluer |
|---|---|---|---|
| 1 | Front-end adaptatif et interactif | C1–C6 | Mises en situation : interface front-end **sans** framework, puis **avec** framework |
| 2 | Back-end sur architectures serveur complexes | C7–C17 | Application back-end avec conception de BDD **SQL et NoSQL** ; API **sécurisée et documentée** |
| 3 | Architectures SI, cloud, industrialisation | C18–C25 | **Rapport d'audit** justifiant une solution technique ; mise en place d'une **CI/CD** |
| 4 | Gestion de projet et amélioration continue | C26–C35 | **Étude préalable** ; rapport d'activité + oral ; **guide de bonnes pratiques** ; **rapport de veille multilingue** + oral |

Ces modalités concernent les apprenants en formation. En VAE, elles indiquent **ce que le jury s'attend à retrouver** dans le livret 2 : un audit argumenté, une CI/CD réelle, une API documentée, une veille en anglais, etc. Le livret gagne à fournir un équivalent issu de l'expérience pour chacune.

## Points de vigilance

1. **Veille technologique multilingue.** La fiche France Compétences cite en bloc 4 « mettre en place une veille technologique » et « la maîtrise de l'anglais ». Le CSV local (C1–C35) n'a pas de compétence dédiée. Il faut vérifier sur le référentiel 3iL remis au candidat et, dans tous les cas, documenter la veille (sources anglophones, n8n auto-hébergé, lecture de docs officielles) dans le livret.
2. **SQL et NoSQL.** Le bloc 2 évalue les deux. Le candidat pratique surtout MongoDB. C10 repose sur AMF et la formation M2i.
3. **API documentée.** Le bloc 2 exige une API documentée. C17 (Swagger) est à produire sur Lexikos.
4. **Rapport d'audit et guide de bonnes pratiques.** Pas d'équivalent formel aujourd'hui. Un document d'architecture Lexikos justifié et un guide de conventions (CLAUDE.md, README, conventions de code) peuvent en tenir lieu.
5. **Seuil 3iL.** 3iL indique qu'il faut couvrir environ 80 à 85 % des compétences pour une démarche recevable.

## Échelle de maîtrise du dossier

| Niveau | Sens |
|---|---|
| 1 | Jamais réalisé ou participation mineure |
| 2 | Réalisé ponctuellement, faible maîtrise, besoin d'une assistance modérée |
| 3 | Réalisé avec maîtrise et/ou de façon récurrente, seul ou en collaboration |
| 4 | Réalisé avec aisance, en autonomie totale |

## Place occupée dans l'activité (à préciser pour chaque compétence)

Mobiliser des moyens, exécuter/produire, encadrer, fixer des objectifs opérationnels, définir des orientations stratégiques.
