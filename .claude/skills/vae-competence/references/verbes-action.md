# Verbes d'action par type de place occupée

| Place | Verbes |
|---|---|
| Exécuter, produire | développe, intègre, code, configure, déploie, teste, corrige, documente, automatise, migre, optimise, refactorise |
| Mobiliser des moyens | choisis, sélectionne, installe, mets en place, provisionne, dimensionne, sollicite |
| Analyser, concevoir | analyse, modélise, conçois, compare, évalue, arbitre, justifie, audite, spécifie |
| Collaborer, encadrer | coordonne, accompagne, relis, forme, explique, présente, anime, arbitre avec |
| Fixer des objectifs | planifie, priorise, définis, estime, fixe, découpe, suis |
| Orienter | oriente, décide, préconise, standardise, impose une convention |

À éviter : « participer à », « aider à », « être en charge de », « s'occuper de », « faire ». Ces verbes masquent ce que le candidat a réellement fait.
